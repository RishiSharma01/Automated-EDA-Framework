<h1>Automated EDA Framework</h1>

<h2>📌 Overview</h2>
<p>
The <strong>Automated EDA Framework</strong> is designed to simplify and speed up the process of
<strong>Exploratory Data Analysis (EDA)</strong>. It automatically generates key statistical summaries
and visual insights, helping users quickly understand datasets and make informed,
data-driven decisions.
</p>

<hr>

<h2>🚀 Features</h2>
<ul>
  <li>Automated data profiling and summary statistics</li>
  <li>Insightful visualizations for numerical and categorical data</li>
  <li>Detection of missing values and data distribution patterns</li>
  <li>Reduces manual effort in exploratory analysis</li>
  <li>Easy to use and adaptable to different datasets</li>
</ul>

<hr>
